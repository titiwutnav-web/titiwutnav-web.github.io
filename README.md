# กล่องฝากไฟล์ (beersbox)

ส่งไฟล์ ลิงก์ และข้อความข้ามคอมพิวเตอร์ด้วยรหัส 6 ตัว เปิดผ่านเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งโปรแกรม ไม่ต้องเข้าสู่ระบบ

- ไฟล์ถูกเข้ารหัส (AES-GCM) ในเบราว์เซอร์ด้วยกุญแจที่สร้างจากรหัส 6 ตัว เซิร์ฟเวอร์เก็บแค่ข้อมูลที่เข้ารหัสแล้ว
- ทุกอย่างถูกลบอัตโนมัติเมื่อหมดเวลา (1 ชั่วโมง ถึง 30 วัน)
- ส่งได้ครั้งละไม่เกิน 200 MB

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (ส่ง/รับ) |
| `worker.js` | API เก็บและอ่านข้อมูลใน Cloudflare KV |
| `wrangler.toml` | ตั้งค่า Cloudflare Worker และ KV namespace `BOX` |

## ตั้งค่าบน Cloudflare (ฟรี)

1. สร้าง KV namespace ชื่อ `beersbox` แล้วเอา ID ไปใส่ใน `wrangler.toml` แทน `REPLACE_WITH_KV_NAMESPACE_ID`
2. Workers & Pages → Create → Import a repository → เลือก repo นี้ แล้ว Deploy
3. (ไม่บังคับ) ตั้งรหัสผ่านสำหรับส่ง: Worker → Settings → Variables and Secrets → เพิ่ม Secret ชื่อ `SEND_PIN`
   เมื่อตั้งแล้ว ฝั่งส่งต้องใส่รหัสผ่านนี้ ฝั่งรับใช้แค่รหัส 6 ตัวเหมือนเดิม

## ข้อจำกัดของแพ็กเกจฟรี

- Workers KV: เขียนได้ประมาณ 1,000 ครั้งต่อวัน (ไฟล์ละ 1 ครั้งต่อ 20 MB + 1 ครั้งต่อการส่ง) และเก็บได้รวม 1 GB
- KV อาจใช้เวลาถึง 1 นาทีกว่าข้อมูลใหม่จะเห็นได้จากทุกที่ ถ้าเปิดรหัสไม่เจอทันทีหลังส่ง ให้รอสักครู่แล้วลองใหม่

## ทดสอบในเครื่อง

