กล่องฝากไฟล์

ฝากไฟล์ ลิงก์ หรือข้อความไว้ที่นี่ แล้วได้รหัส 8 ตัว เปิดหน้านี้บนอีกเครื่อง พิมพ์รหัสเดียวกัน ก็ดาวน์โหลดได้ทันที ไม่ต้องติดตั้งโปรแกรม ไม่ต้องเข้าสู่ระบบ

ตั้งค่าครั้งแรก (ทำครั้งเดียว)

  1. สร้าง GitHub token ที่ github.com/settings/personal-access-tokens/new
  2. Repository access เลือก Only select repositories → beersbox-data
  3. Permissions → Repository permissions → Contents เลือก Read and write แล้วกด Generate token
  4. วาง token ด้านล่าง แล้วตั้งรหัสผ่านสำหรับส่ง (ยาวอย่างน้อย 10 ตัว)

token จะถูกล็อกด้วยรหัสผ่านนี้ก่อนบันทึก เครื่องอื่นจะใช้แค่รหัสผ่าน ไม่ต้องใส่ token อีก
